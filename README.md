# PatientPlanner

Приложение для iOS (SwiftUI + SwiftData) — планировщик записи пациентов по врачам/кабинетам,
по образцу таблицы записи из клиники (колонка на каждого врача, слоты по времени).

## Как открыть и запустить

1. Установите Xcode (актуальная версия из App Store).
2. Распакуйте архив и откройте `PatientPlanner.xcodeproj`.
3. Выберите симулятор или подключённый iPhone/iPad и нажмите ▶️ (Run).
   Минимальная версия — iOS 17.0.
4. При первом запуске в приложении автоматически создаются 3 демонстрационных
   врача ("Терапевт 1/2/3") — их можно переименовать, удалить или добавить своих
   на вкладке **«Врачи»**.

## Возможности

- **Расписание** — выбор даты, горизонтальная прокрутка колонок по врачам,
  запись/просмотр/редактирование/удаление записей на приём.
- **Пациенты** — поиск по всем записям по имени или телефону.
- **Врачи** — добавление, редактирование, удаление, перестановка врачей и кабинетов, выбор цвета.
- Возможность **заблокировать слот** времени (как "Заблокировано" на исходной таблице).
- Пометка **«Предварительная запись»** и поле для заметок (например, "тел. жены, если не ответит").

## Хранение данных

Все данные (врачи и записи пациентов) хранятся **только локально на устройстве**
через SwiftData (локальная база SQLite в песочнице приложения). Никуда в интернет
ничего не отправляется, никакого бэкенда нет. Это значит:

- Данные не пропадают при перезапуске приложения.
- Данные привязаны к конкретному устройству/симулятору (если нужен единый список
  на несколько устройств/сотрудников — потребуется добавить синхронизацию,
  например через CloudKit — дайте знать, могу помочь дальше).

## Структура проекта

```
PatientPlanner/
  PatientPlannerApp.swift       — точка входа, настройка локального хранилища
  RootView.swift                — вкладки (TabView)
  ColorHex.swift                — цвет врача из hex-строки
  Models/Models.swift           — модели Doctor и Appointment (SwiftData)
  Views/ScheduleView.swift      — расписание по дням/врачам
  Views/AppointmentFormView.swift — форма добавления/редактирования записи
  Views/DoctorsView.swift       — управление врачами
  Views/PatientsSearchView.swift — поиск пациентов
```

## Возможные доработки

- Печать/экспорт расписания на день.
- Напоминания (push-уведомления) о приёме.
- Синхронизация между устройствами (CloudKit/iCloud).
- Импорт списка пациентов из CSV/Excel.
