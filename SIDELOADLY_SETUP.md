# Установка PatientPlanner на iPhone через Sideloadly (бесплатно, без Apple Developer)

Никаких сертификатов, .p12 и провижн-профилей больше не нужно — их делает
Sideloadly сам, на лету, через ваш обычный бесплатный Apple ID.

## Шаг 1. Собрать .ipa через GitHub Actions

1. Запушьте проект в свой GitHub-репозиторий (публичный — тогда сборка
   бесплатная и без лимитов по минутам).
2. Зайдите во вкладку **Actions** репозитория → workflow
   **"Build unsigned IPA (for Sideloadly)"** → **Run workflow** (или просто
   сделайте `git push` в ветку `main` — соберётся автоматически).
3. Дождитесь зелёной галочки (обычно 3-5 минут).
4. Откройте завершившийся run → внизу страницы раздел **Artifacts** →
   скачайте **PatientPlanner-ipa** (это zip, внутри — `PatientPlanner.ipa`).

## Шаг 2. Установить Sideloadly на Windows

1. Скачайте с официального сайта **sideloadly.io** → Windows-версию.
2. Установите. Если ещё не стоит — Sideloadly попросит поставить
   **iTunes / Apple Mobile Device Support** (для драйверов USB) — соглашайтесь,
   можно через официальный установщик iTunes с apple.com/itunes или Microsoft Store.

## Шаг 3. Подключить iPhone и поставить приложение

1. Подключите iPhone к компьютеру по кабелю.
2. На телефоне при запросе — **"Доверять этому компьютеру"** → Доверять.
3. Откройте Sideloadly, перетащите `PatientPlanner.ipa` в окно программы.
4. В поле **Apple ID** впишите свой обычный Apple ID (email).
   Если у Apple ID включена двухфакторная аутентификация (обычно да) —
   Sideloadly попросит **app-specific password**, а не обычный пароль:
   создаётся на **appleid.apple.com → Sign-In and Security →
   App-Specific Passwords**.
5. Нажмите **Start**. Sideloadly подпишет приложение вашим Apple ID и
   поставит на телефон.

## Шаг 4. Разрешить запуск на самом iPhone

После установки при первом запуске iOS покажет "Ненадёжный разработчик":
**Настройки → Основные → VPN и управление устройством** → найдите свой
Apple ID в разделе "Приложение разработчика" → **Доверять**.

## Ограничения бесплатного Apple ID (это ограничения самой Apple, не мои)

- Приложение **перестаёт запускаться через 7 дней** — нужно заново
  подписать через Sideloadly (просто повторить Шаг 3, ipa тот же).
  Sideloadly также умеет напоминать/переподписывать по расписанию.
- На одном Apple ID одновременно **максимум 3** таких приложения.
- Установить можно **только на устройства, физически подключаемые к компьютеру**
  под этим Apple ID — раздать ссылкой знакомым нельзя (это уже TestFlight/App Store,
  требует платного аккаунта).

## Если нужно будет обновить приложение

Просто внесите правки в код → `git push` → новый `.ipa` появится в Artifacts
того же workflow → повторите Шаг 3 в Sideloadly с новым файлом.
